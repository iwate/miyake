# Jean Miyake — Portfolio

Storage repo for the portfolio of Jean Miyake (ミヤケ). Each work is a single HTML file, kept as dated snapshots.

## Contents

| File | Description |
|---|---|
| `miyake-portfolio-2026-09-17.html` | The portfolio itself (SKILL N°001). Paper × ink × vermillion minimal layout, Shippori Mincho, one CTA style only |

## Viewing

Open in a browser. No build, no dependencies.

```sh
open miyake-portfolio-2026-09-17.html
```

## Conventions

- When a new version is made, add it as `miyake-portfolio-YYYY-MM-DD.html` and keep old versions as history (git already tracks history — add a new file only when you want an explicit snapshot)
- Implementation follows Miyake's aesthetic (the skill): assertive, one point instead of repetition, at most one animation
